Introduction

So we’ll be asking questions about computing the number of output channels (aka “feature maps / activation maps”) coming from convolutional layers as well as the shape of those map(s).

In this assignment, we will use the terms activation maps and feature maps interchangeably. Each filter in a Conv2D layer produces one activation map.

Let’s say we have a collection of monochome images (1 color channel) of size 24 x 24 as input into the following simple two-layer architecture:

Conv2D(in_channels=1, out_channels=12, kernel_size=3, stride=1, padding=1) -> MaxPool2D(kernel_size=2, stride=2)

What would be the output tensor from this from this sequence of layers? We would need to work through each layer and there are easy formulas for this. the first layer involved a Connv2D layer and we have a formula for Conv2D layers. The easy part here is that we already know that we will have 12 activation maps because of the out_channels=12 argument in the layer declaration.

Note that we also have symmetry in our image sizes in that both the height and width are the same (24 x 24) so we need only compute the size of the spatial output once.

\[ \text{Output Size} = \frac{\text{Input Size} + 2 \times \text{Padding} - \text{Kernel Size}}{\text{Stride}} + 1 \]

We want to compute the shape of the features maps coming from this layer. It’s easy to do:

\[ \text{24} = \frac{\text{24} + 2 \times \text{1} - \text{3}}{\text{1}} + 1 \]

So we have a tensor with 12 activation maps of size 24 x 24 - (12 x 24 x 24) which we can then pass to the MaxPool2D layer.

For the MaxPool2D layer there is a formula to compute the shape of the 12 activation maps. Note that MaxPool2D layers do not impact the number of incoming activation maps.

\[ \frac{\text{Input Size} - \text{Kernel Size}}{\text{Stride}} + 1 \]

Plugging in the numbers gives

\[ \text{12} = \frac{\text{24} - \text{2}}{\text{2}} + 1 \]

So the shape of the output tensor would be 8 x 12 x 12

import matplotlib.pyplot as plt
import numpy as np
import torch

# Function to show sample images from the dataset
def show_sample_images(dataset, num_images=10):
    fig, axes = plt.subplots(2, 5, figsize=(10, 5))
    axes = axes.flatten()

    # Normalization stats used for SVHN dataset
    mean = np.array([0.4377, 0.4438, 0.4728])
    std = np.array([0.1980, 0.2010, 0.1970])

    for i in range(num_images):
        img, label = dataset[i]

        # Convert tensor to NumPy array
        img = img.permute(1, 2, 0).numpy()

        # Unnormalize
        img = img * std + mean
        img = np.clip(img, 0, 1)  # Ensure valid range for imshow

        axes[i].imshow(img)
        axes[i].set_title(f"Label: {label}")
        axes[i].axis("off")

    plt.show()

# Display 10 sample images from the training set
show_sample_images(train_set)
